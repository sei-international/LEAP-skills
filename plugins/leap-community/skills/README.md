# Community skills

This folder holds skills contributed by LEAP users. A contributed skill lands here first,
in the `leap-community` plugin, after a maintainer has reviewed the pull request. Once it
has been tested on a sample area and reviewed again, it moves to the `leap-core` plugin.

There are no community skills yet. To add one, read [CONTRIBUTING.md](../../../CONTRIBUTING.md)
at the top of the repository.
